# Multi-Source Fusion

These cases combine analytical results with audience, campaign, compliance,
placement, and asset evidence to produce one coherent customer-facing image.

| Case | Deliverable | Core operations |
| --- | --- | --- |
| `multi_source_fusion_001` | HelioGrid Instagram campaign | Contribution calculation, product/region/track/program routing, current copy, disclosures, and assets. |
| `multi_source_fusion_003` | NovaPack Instagram campaign | Contribution and segment ranking, current paid-social revision, audience/compliance package, identity and assets. |

Review emphasis: all downstream choices must use the same winning analytical
basis and routing path. Do not mix compatible-looking facts from different
products, audiences, revisions, placements, or objectives.
