# Design Specification

These cases require the agent to resolve current campaign, placement, copy,
rights, and asset constraints before producing a compliant creative.

| Case | Deliverable | Core operations |
| --- | --- | --- |
| `design_specification_001` | FlowForge LinkedIn launch image | Freeze-time placement/message/activation joins and approved asset-board resolution. |
| `design_specification_002` | Open Studio Day Instagram Story | Freeze-time profile, activation/session package, copy override, and asset validity. |
| `design_specification_004` | LedgerLite 4:5 paid-social ad | Release package, disclosures, badge copy, platform rules, rights, and UI asset consistency. |
| `design_specification_007` | BrightBite in-app banner | Release plus retail activation, locked claims/preparation content, and six-asset verification. |

Review emphasis: validate the controlling freeze time, package precedence,
market/placement scope, rights window, exact copy, and prohibited superseded or
internal material. Asset libraries may be large, but only task-relevant approved
assets should appear in the final image.
