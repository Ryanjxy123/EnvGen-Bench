# Data Insight

These cases require the agent to derive and prioritize quantitative findings
before presenting them as an infographic or decision view.

| Case | Deliverable | Core operations |
| --- | --- | --- |
| `data_insight_001` | Annual sales summary infographic | Net-revenue calculation, monthly/quarterly comparison, category and region ranking. |
| `data_insight_002` | Warehouse quality decision brief | Effective-dated profiles, revision filtering, window comparison, incident weighting, intervention choice. |
| `data_insight_006` | Campus energy review snapshot | Meter eligibility, calibration, multi-meter aggregation, thresholds, baseline and intensity analysis. |
| `data_insight_011` | Q4 store operations triage snapshot | SQLite joins, quarter comparison, location/region ranking, risk and action selection. |

Review emphasis: reproduce the eligible population, calculation basis,
aggregation scope, ranking, and every value selected for the image.
