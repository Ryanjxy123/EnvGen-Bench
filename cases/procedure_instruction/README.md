# Procedure Instruction

These cases turn manuals and scoped local rules into a safe, ordered visual
workflow that can be followed without reopening the sources.

| Case | Deliverable | Core operations |
| --- | --- | --- |
| `procedure_instruction_001` | Epson room handover guide | Select the room-network Windows workflow and express setup, presentation, ending, and shutdown in eight steps. |
| `procedure_instruction_003` | BIO 214 ELISA bench card | Resolve class context and approved bulletins, reconcile manual/deck instructions, derive station quantities and safety gates. |

Review emphasis: verify source precedence, step order, quantities, validation
and safety boundaries, plus explicit exclusion of alternative or superseded
procedures.
