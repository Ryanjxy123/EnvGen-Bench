# Data Selection

These cases require the agent to resolve candidate histories and select the
correct final set under explicit rules, caps, and tie-breaks.

| Case | Deliverable | Core operations |
| --- | --- | --- |
| `data_selection_002` | Climate microgrant award announcement | Dated histories, eligibility, ranking, district/focus constraints, running budget cap. |
| `data_selection_003` | Cafe lunch-specials display | As-of SQLite state, inventory deductions, service adjustment, five-item portfolio and quick picks. |
| `data_selection_005` | Volunteer recruitment poster | Version resolution, openings after holds, safety/readiness rules, ranked five-role portfolio. |
| `data_selection_006` | Museum exhibit feature panel | Object eligibility, weighted ranking, then ordered zone, case, and installation replacements. |

Review emphasis: verify every exclusion and replacement, not only the displayed
winners; final ordering and item-to-value pairings must remain unambiguous.
